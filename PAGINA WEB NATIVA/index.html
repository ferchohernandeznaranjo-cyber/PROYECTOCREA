Somos un emprendimiento que vende bebidas energizantes naturales hechas a base de kombucha, que contienen muchos beneficios para la salud

Nativa nace como respuesta a dos grandes problemas que tiene el mercado de bebidas energizantes, son altamente dañinas para la salud y contaminan demasiado.
Es aqui que creamos Nativa como un alternativa saludable y sostenible para el medio ambiente, al mismo tiempo que representa a traves de sus sabores a las regiones del Ecuador
